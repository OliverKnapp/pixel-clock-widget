# 📱 Pixel Clock

> Android Pixel-style Material You desktop Clock widget with Google Sans typography for DankMaterialShell & Hyprland

A standalone desktop widget built for **DankMaterialShell (DMS)** and **Hyprland** following Google's **Material 3 / Material You** design language.

---

## ✨ Features
- **Material You Aesthetic:** Dynamic pastel surfaces, pill containers, and smooth geometry.
- **DankMaterialShell Integration:** Built as a native QML desktop plugin component.
- **Hyprland Native:** Flawless rendering on Wayland with active workspace & compositor awareness.

---

## 🚀 Installation & Usage

### Method 1: Automatic via Oliver's Dotfiles
This widget is automatically integrated into Oliver's dotfiles at:
`~/.config/DankMaterialShell/plugins/pixelClock/`

### Method 2: Manual Installation in DMS
Clone this repository directly into your DMS plugins folder:
```bash
mkdir -p ~/.config/DankMaterialShell/plugins
git clone https://github.com/OliverKnapp/pixel-clock-widget.git ~/.config/DankMaterialShell/plugins/pixelClock
```
Then restart DMS:
```bash
dms restart
```
